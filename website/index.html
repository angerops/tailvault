TailVault

A macOS GUIfor Setec.

TailVault is a graphical interface for Setec. Browse, create and manage secrets using your Mac’s existing Tailscale identity.

Install with Homebrew

brew install angerops/tap/tailvault

macOS 15 Sequoia or laterApple silicon

Connect Tailscale, then enter your Setec server in the app.

Access controlled by Setec. The same path permissions as the CLI.
